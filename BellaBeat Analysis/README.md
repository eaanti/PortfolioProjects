# Bellabeat Case Study: Smart Device Usage Analysis

## Overview

This project analyzes smart device fitness data to identify user activity, sleep, and lifestyle patterns that can support Bellabeat’s marketing strategy.

## Tools Used

* SQL Server – Data cleaning, transformation, and analysis
* Tableau – Dashboard creation and visualization

## Analysis Performed

* Cleaned and prepared fitness tracker datasets
* Joined activity, intensity, and sleep data
* Analyzed activity trends, sleep patterns, calories, and sedentary behavior
* Created interactive Tableau dashboards

## Key Insights

* Activity and calorie levels varied throughout the week, with Saturday showing the highest overall activity.
* Users spent significant time sedentary, highlighting opportunities to encourage movement.
* Activity intensity was associated with higher calorie expenditure.

## Recommendations

* Encourage users to increase daily activity.
* Promote strategies to reduce sedentary time.
* Use user behavior patterns to improve engagement campaigns.
